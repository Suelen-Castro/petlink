# Petlink

Protótipo navegável do Petlink, feito pelo grupo Hello World na disciplina de Experiência do Usuário (Fatec Jacareí).

O Petlink aproxima pessoas que querem adotar cães e gatos das ONGs que cuidam desses animais. O protótipo tem quatro páginas:

- `home.html`: início, busca e perfil dos animais
- `pets-perdidos.html`: avisos de animais perdidos, avistados e encontrados
- `marketplace.html`: catálogo de parceiros
- `ong.html`: painel da ONG

O arquivo `mapa-do-site.html` mostra a organização das áreas. Todos os dados são de exemplo.
